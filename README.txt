How to use:
1. Double-click launch.bat.
2. If PyMuPDF is missing, run install.bat, then launch.bat.
3. If there is still an error, run diagnose.bat and share a screenshot.
4. Create a desktop shortcut to launch.bat. Keep the application folder in place.

Features: replace text (simple ASCII layouts), merge PDFs, split PDFs,
reorder pages, set opening passwords, remove opening passwords with permission.
Original PDFs are not overwritten. Examine all edited PDFs visually.

Python 3 and the PyMuPDF package are needed for launch.bat.
If desired, build_exe.bat may produce a standalone Windows exe, but must
be run on Windows and its success depends on your Python/PyInstaller setup.
Check your organization's IT policy before using on company devices/files.
